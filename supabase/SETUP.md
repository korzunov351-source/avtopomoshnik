# Подключение облачной базы АвтоПомощник KZ

## Что уже подготовлено
Файл `supabase/schema.sql` создаёт таблицы профилей, объявлений мастеров, автомобилей, истории ТО, избранного и отзывов. Включены Row Level Security (RLS) политики: личные данные доступны владельцу аккаунта, публичный каталог показывает только одобренные объявления, а публикация и блокировка объявлений предназначены для администратора.

## Создание проекта Supabase
1. Открой https://supabase.com/ и зарегистрируйся.
2. Создай новый проект с регионом, ближайшим к Казахстану (например, Singapore, если доступен).
3. Задай надёжный пароль базы данных и сохрани его отдельно.
4. После создания открой **SQL Editor -> New query**.
5. Скопируй целиком содержимое файла `supabase/schema.sql` из репозитория и нажми **Run**.
6. Открой **Project Settings -> API** (или **Data API**): скопируй **Project URL** и публичный **anon/publishable key**.

## Что передать для подключения приложения
Нужны только:
- Project URL вида `https://....supabase.co`
- публичный anon/publishable key

Публичный ключ предназначен для клиентского приложения и работает вместе с RLS. **Не присылай** пароль базы данных, `service_role` / secret key, токены доступа или резервные ключи. Их нельзя помещать в APK или GitHub.

## Важные ограничения первого этапа
- Схема базы подготовлена, но облачная синхронизация ещё не активирована в APK.
- Платёж Kaspi, автоматическая проверка оплаты, push-уведомления и загрузка фотографий требуют отдельной настройки и не считаются подключёнными.
- После получения URL и публичного ключа можно добавить регистрацию/вход, синхронизацию профиля мастера и общий каталог объявлений. Администраторский доступ нужно выдавать безопасно через Supabase Auth app_metadata, а не через поле, которое пользователь может изменить сам.
