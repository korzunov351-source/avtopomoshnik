# Подключение облачной базы АвтоПомощник KZ

## Что уже подготовлено
Файл `supabase/schema.sql` создаёт таблицы профилей, объявлений мастеров, автомобилей, истории ТО, избранного и отзывов. Включены Row Level Security (RLS) политики: личные данные доступны владельцу аккаунта, публичный каталог показывает только одобренные объявления, а публикация и блокировка объявлений предназначены для администратора. В Android-приложение добавлены регистрация по email/паролю, вход/выход, сохранение профиля пользователя и отправка объявления мастера в общую базу со статусом `pending`. Публичный каталог загружает только объявления со статусом `active`.

## Создание проекта Supabase
1. Открой https://supabase.com/ и зарегистрируйся.
2. Создай новый проект с регионом, ближайшим к Казахстану (например, Singapore, если доступен).
3. Задай надёжный пароль базы данных и сохрани его отдельно.
4. После создания открой **SQL Editor -> New query**.
5. Скопируй целиком содержимое файла `supabase/schema.sql` из репозитория и нажми **Run**.
6. Открой **Project Settings -> API** (или **Data API**): скопируй **Project URL** и публичный **anon/publishable key**.

## Что передать для подключения приложения
Нужны только:
- Project URL вида `https://....supabase.co`
- публичный anon/publishable key

Публичный ключ предназначен для клиентского приложения и работает вместе с RLS. **Не присылай** пароль базы данных, `service_role` / secret key, токены доступа или резервные ключи. Их нельзя помещать в APK или GitHub.

## Что ещё нужно сделать в Supabase
- Обязательно выполнить `supabase/schema.sql` в SQL Editor. Пока таблицы и политики не созданы, регистрация может работать, но профиль и каталог будут выдавать ошибку базы.
- В Authentication → URL Configuration укажи адрес сайта, если будешь использовать подтверждение email через ссылку. В мобильном приложении вход выполняется по email и паролю.

## Важные ограничения первого этапа
- Регистрация и каталог используют Supabase напрямую из Android WebView через публичный ключ и RLS.
- Объявления мастеров отправляются на модерацию. Самостоятельно опубликовать или продвинуть объявление обычный пользователь не может.
- Платёж Kaspi, автоматическая проверка оплаты, push-уведомления, загрузка фотографий и настоящая серверная админ-панель пока не подключены.
- Не выдавай себе роль администратора через обычное поле профиля. Администраторский доступ нужно назначать только безопасно через Supabase Auth `app_metadata`.
